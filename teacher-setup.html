Sourcebook: turn on the Teacher view (3 minutes, once)

You don't paste anything. Nothing changes for students, and IT doesn't need to do anything.

  1. Open the Sourcebook Teacher project
  2. On the left, next to Services, click ＋ → pick Google Classroom API → Add.
  3. Deploy → New deployment → ⚙ type: Web app.
    Execute as: Me · Who has access: Anyone within barkaionline.org (your school) → Deploy.
  4. Google asks for permission: Allow. It asks to see your Classroom classes, rosters and students' emails (read-only), and to use only the files this app makes in your Drive.
  5. Copy the Web app URL and send it to Tab.
What the Teacher view shows
Your Classroom classes → each student's number of saved sources and last-active date → each student's list: title, authors, year, type, ✓ Cited, date saved, a link to the original, and counts like "2 highlights · 1 note". Export a class as a spreadsheet.
Only a class's own Classroom teacher sees its students. Students never see it. No PDFs or note text are copied; students' files stay in their own Drive and nothing is shared. The small per-student lists are kept in a folder this app makes in your Drive ("Sourcebook class data (Tab) - do not edit").
