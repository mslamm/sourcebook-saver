Sourcebook: one-time settings update (2 minutes)

Lets Sourcebook look up citation details through Google's servers, so the school network can't block them. Nothing changes for students or IT.

  1. Copied ✓
  2. Open the Sourcebook project, click appsscript.json on the left, press Ctrl+A, Ctrl+V, then Ctrl+S.
    Don't see appsscript.json? ⚙ Project Settings → tick "Show appsscript.json manifest file in editor".
  3. Deploy → Manage deployments → select the Web app → ✏️ → Version: New version → Deploy.
  4. Done. The Saver's address stays the same.

What changes: four public citation databases (Crossref, DataCite, OpenAlex, ERIC) are added to the list of addresses Sourcebook may contact. Every existing setting and permission stays exactly as it is.
