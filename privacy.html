Privacy policy

Sourcebook (Google Docs add-on) and Sourcebook Saver (Chrome extension)

In short: Sourcebook keeps a student's sources in that student's own Google account. There is no Sourcebook server, no advertising and no analytics. Nothing is sold or shared.

What it stores, and where

Saved sources (citation details, the PDF, the student's highlights and notes) are stored as files in the student's own Google Drive, in a Sourcebook folder. The app can only see files it created itself (Google's drive.file permission). It cannot see the rest of the student's Drive.

Citations in a paper are stored inside that Google Doc, so the paper still formats correctly when a teacher opens it.

Settings (for example the chosen citation style) are stored in Google's per-user storage for the add-on.

What it sends outside Google

When a student saves a source or looks up a book, Sourcebook sends only the identifier it needs to public catalogue services to get the citation details: the DOI or title to doi.org, Crossref and DataCite, and the ISBN to Open Library and Google Books. Citation style files come from the public Citation Style Language repository. No personal information is sent to any of these services. Sourcebook's own program code is loaded from a file the teacher keeps in Google Drive; nothing about students is sent there.

What the Chrome extension reads

The extension reads the page or PDF a student is viewing only when they click Save, so it can build the citation and a copy of the article. It does not track browsing history.

Permissions

Edit the Google Doc the student has open (documents), show the sidebar (script.container.ui), look up citation details (script.external_request), create and open its own files in the student's Drive (drive.file), and know which school account is signed in (userinfo.email), used only to give the teacher her test version.

Removing it

The school can remove both parts from the Google Admin console at any time. A student's saved files stay in their own Drive, and citations already in papers stay as normal text.
